# NEET Prep Tracker

A small, mobile-friendly study tracker for NEET preparation. It runs as a static web page and needs no build tools or dependencies.

## Run it

1. Open `index.html` in a modern browser, or use GitHub Pages to publish the repository as a website.
2. Add today's study tasks and mark them complete to track study time.
3. Add chapters, then check them off to calculate subject-wise syllabus progress.
4. Log mock scores and add revision reminders.

## Data and privacy

The app stores its data in the browser's `localStorage` on the device where it is used. It does not send study data to a server. Clearing browser data or switching browsers/devices may remove or hide the saved tracker data.

## Current limitations

- No account or cloud sync.
- Syllabus completion is calculated from the chapters you add; the app does not preload an official chapter list.
- Study hours are based on the estimates attached to tasks you mark complete.
